# Notes/Tasks Feature - Инструкция

## Что реализовано

✅ **CRUD операции:**
- Создание заметок/задач
- Чтение списка в реальном времени
- Обновление заметок/задач
- Удаление заметок/задач

✅ **Real-time обновления:**
- Автоматическое обновление списка через `snapshots()`
- Изменения видны сразу всем пользователям

✅ **Пагинация:**
- Загрузка по 10 элементов
- Кнопка "Загрузить ещё"
- Автоматическая загрузка при скролле (80% прокрутки)

✅ **Поиск:**
- Поиск по заголовку (title)
- Debounce 500ms для оптимизации

✅ **Фильтры:**
- По статусу (для задач)
- По категории
- Комбинирование фильтров
- Кнопка очистки фильтров

✅ **Правила безопасности:**
- Доступ только для авторизованных пользователей
- Пользователь видит только свои записи (userId)
- Проверка при создании/обновлении

## Структура данных

### NoteEntity
- `id`: ID документа (null для новых)
- `title`: Заголовок (обязательно)
- `description`: Описание (обязательно)
- `type`: Тип (note или task)
- `status`: Статус (pending, inProgress, completed, cancelled) - только для tasks
- `category`: Категория (опционально)
- `tags`: Список тегов (опционально)
- `userId`: ID пользователя (автоматически)
- `createdAt`: Дата создания
- `updatedAt`: Дата обновления

## Использование

### 1. Запуск build_runner

```bash
flutter pub get
flutter pub run build_runner build --delete-conflicting-outputs
```

### 2. Деплой правил Firestore

```bash
firebase deploy --only firestore:rules
```

См. `FIRESTORE_DEPLOY.md` для подробностей.

### 3. Навигация

- На HomePage есть карточки "Заметки" и "Задачи"
- При нажатии открывается список соответствующей коллекции
- Кнопка "+" для создания новой записи
- Нажатие на карточку для редактирования

## Особенности

### Real-time обновления
Список автоматически обновляется при:
- Создании новой записи
- Обновлении существующей
- Удалении записи

### Пагинация
- Первая загрузка: 10 элементов
- При скролле до 80% автоматически загружается следующая страница
- Кнопка "Загрузить ещё" для ручной загрузки

### Поиск
- Работает только по заголовку (title)
- Debounce 500ms
- При очистке поиска возвращается к обычному списку

### Фильтры
- Статус: только для задач (tasks)
- Категория: для всех типов
- Можно комбинировать фильтры
- Кнопка очистки возвращает к полному списку

## Правила безопасности

Файл `firestore.rules` содержит правила:
- Только авторизованные пользователи могут читать/писать
- Пользователь видит только свои записи
- При создании проверяется соответствие userId

## Следующие шаги

1. Запустите `flutter pub run build_runner build --delete-conflicting-outputs`
2. Задеплойте правила: `firebase deploy --only firestore:rules`
3. Запустите приложение: `flutter run`
4. Войдите в систему
5. Нажмите на "Заметки" или "Задачи" на HomePage
